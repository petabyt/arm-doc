TRCEXTINSELR<n>, Trace External Input Select Register <n>, n = 0 - 3

The TRCEXTINSELR<n> characteristics are:

Purpose

Use this to set, or read, which External Inputs are resources to the trace unit.

The name TRCEXTINSELR is an alias of TRCEXTINSELR0.

Configuration

External register TRCEXTINSELR<n> bits [31:0] are architecturally mapped to AArch64 System register TRCEXTINSELR<n>[31:0].

This register is present only when FEAT_ETE is implemented and FEAT_TRC_EXT is implemented. Otherwise, direct accesses to TRCEXTINSELR<n> are RES0.

Attributes

TRCEXTINSELR<n> is a 32-bit register.

evtCount, bits [15:0]

PMU event to select.

The event number as defined by the Arm ARM.

Software must program this field with a PMU event that is supported by the PE being programmed.

If evtCount is programmed to a PMU event that is reserved or not supported by the PE, the behavior depends on the PMU event type: FEAT_PMUv3p8 is implemented and this field is programmed to an event that is reserved or not supported by the PE, Arm recommends that the External Input Selector is not active and the value returned by a direct or external read of this field is the value written to the field.

Otherwise, if evtCount is programmed to a PMU event that is reserved or not supported by the PE, the behavior depends on the value written:

  • For the range 0x0000 to 0x003F, then the ExternalPMU Inputevent Selector is not active, and the value returned by a direct or external read of thisthe evtCount field is the value written to the field.
  • IfFor FEAT_PMUv3p1IMPLEMENTATION DEFINED isPMU implementedevents, forit the rangeis 0x4000UNPREDICTABLE towhat PMU event, if any, is counted, and the value returned by a direct or external read of the evtCount field is 0x403FUNKNOWN, Arm recommends that the External Input Selector is not active and the value returned by a direct or external read of this field is the value written to the field..
  • For other values, it is UNPREDICTABLE whether the External Input Selector is active and the value returned by a direct or external read of this field is UNKNOWN.

UNPREDICTABLE means the PMU event must not expose privileged information.

The reset behavior of this field is:

  • On a Trace unit reset, this field resets to an architecturally UNKNOWN value.

Accessing TRCEXTINSELR<n>

Must be programmed if any of the following is true: TRCRSCTLR<a>.GROUP == 0b0000 and TRCRSCTLR<a>.EXTIN[n] == 1.

If the trace unit is not in the Idle state it is CONSTRAINED UNPREDICTABLE whether writes to this register are ignored.

TRCEXTINSELR<n> can be accessed through the external debug interface:

ComponentOffsetInstance
ETE0x120 + (4 * n)TRCEXTINSELR<n>

Accessible as follows:

  • When OSLockStatus(), or !AllowExternalTraceAccess(addrdesc), or !IsTraceCorePowered(), accesses to this register generate an error response.
  • When n >= NUM_TRACE_EXTERNAL_INPUT_SELECTOR_RESOURCES, accesses to this register are RES0.
  • Otherwise, accesses to this register are RW.
