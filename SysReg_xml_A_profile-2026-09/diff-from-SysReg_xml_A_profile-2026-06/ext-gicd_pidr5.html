GICD_PIDR5, Distributor Peripheral Identification Register 5

The GICD_PIDR5 characteristics are:

Purpose

Provides information to identify an external Distributor component.

Configuration

This register is present only when FEAT_GICD_PIDR is implemented. Otherwise, direct accesses to GICD_PIDR5 are RES0.

A copy of this register is provided for each Distributor.

Attributes

GICD_PIDR5 is a 32-bit register.

Field descriptions

313029282726252423222120191817161514131211109876543210
RES0

Bits [31:0]

Reserved, RES0.

Accessing GICD_PIDR5

GICD_PIDR5 can be accessed through the memory-mapped interfaces:

ComponentFrameOffsetInstance
GIC DistributorDist_base0xFFD4GICD_PIDR5

Accesses to this register are RO.
